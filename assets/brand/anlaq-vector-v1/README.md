# ANLAQ combined identity — vector artwork v1

Reconstructed from the selected Clear Perspective + Quiet Authority concept. The geometric framing symbol is paired with a serif ANLAQ wordmark and custom champagne Q tail.

## Files
- Primary: navy and champagne; transparent background.
- Reversed: ivory and champagne; transparent, for dark backgrounds.
- Monochrome dark/light and pure black: single-colour alternatives.
- No-descriptor versions: compact horizontal applications.
- Symbol primary/dark/light: standalone brand mark.
- Favicon: simplified presentation on a square ivory canvas.
- On-ivory and on-navy: ready-to-use background versions.

All SVG lettering is outlined: no embedded raster images, external resources or font dependencies. Individual paths remain editable. Lettering is reconstructed from Playfair Display Medium with a customised Q, and Inter Regular for the descriptor; it is not an exact trace of the generated concept. Font licences are included.

## Colours
Navy #0F2744 · Champagne #C6A15B · Ivory #FBF8F3.
Use navy or ivory for text. Champagne is an accent, not small body text.

## Usage
Keep at least half the capital-letter height clear around the mark. Use the no-descriptor logo when the descriptor becomes hard to read. Use the standalone symbol for avatars and favicons. Do not stretch, add effects or rearrange the components. Initial suggested minimum width: 360px with descriptor, 180px without; confirm readability in each application. At 16px the two-part symbol is necessarily compact; larger icons preserve its gap more clearly.

This package is separate from the website. No deployment or production replacement has been performed.
